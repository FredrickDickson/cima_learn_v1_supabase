# **1. Frontend (Flutter)**

* **Flutter** (mobile + web support)
* **State Management**

  * **Riverpod** (recommended for scalability)
  * Alternatives: Provider, Bloc, GetX
* **Routing**

  * `go_router` or `auto_route`
* **UI / Animations**

  * Material 3 widgets
  * `flutter_animate` or `animate_do` for animations
* **Networking**

  * `dio` or `http` for REST API calls
* **Local Storage**

  * `shared_preferences` (simple data)
  * `hive` or `sqflite` (offline caching of lessons/progress)
* **Push Notifications**

  * `firebase_messaging` or OneSignal
* **Video Player**

  * `video_player` + `chewie` for lessons
* **File Handling**

  * `file_picker` for uploads if needed (instructor app)

---

# **2. Backend**

Even if the frontend is Flutter, you need a backend to manage courses, users, and payments. Options:

### **A. Firebase / Supabase (Serverless, Fast)**

* **Supabase** (PostgreSQL + Auth + Storage)

  * Authentication: email/password, social logins
  * Database: courses, users, enrollments, transactions
  * Storage: lesson videos, PDFs
  * Realtime subscriptions for live chat/comments
* **Advantages**

  * No need to manage server
  * Easy Paystack integration via backend function

### **B. Custom Backend (Node.js / NestJS / Django / FastAPI)**

* **Node.js + Express/NestJS** (JavaScript/TypeScript)
* **Django or FastAPI** (Python)
* Handles:

  * Authentication
  * Course CRUD
  * Enrollments
  * Paystack webhook & payment verification
  * Notifications
* **Database:** PostgreSQL (relational, structured for courses & transactions)

---

# **3. Database**

* **PostgreSQL** (structured, supports transactions well, works with Paystack)
* Tables:

  * `users`, `courses`, `sections`, `lessons`, `enrollments`, `transactions`, `reviews`, `quizzes`
* Optional: **Redis** for caching heavy queries like “top courses”

---

# **4. Storage**

* **Videos & PDFs**

  * Supabase Storage
  * AWS S3 (alternative)
* Secure links for course videos (so only enrolled students can access)

---

# **5. Payments (Paystack)**

* **Frontend:** Use `paystack_flutter` package
* **Backend:**

  * Webhook endpoint to verify payments
  * Update enrollment status after verification
* **Records:** Store transaction info in database

---

# **6. Authentication**

* Supabase Auth or Firebase Auth
* JWT for secure API calls
* Role-based access: student / instructor / admin

---

# **7. Analytics / Engagement**

* **Realtime data**: Supabase subscriptions or Firebase Firestore
* Track:

  * Student progress
  * Course completion
  * Instructor revenue
* Optional: Mixpanel / Google Analytics

---

# **8. Optional Enhancements**

* Offline video download: `flutter_downloader` or `video_player` caching
* Quiz & Assignment scoring: local storage + backend sync
* Chat / comments: Supabase Realtime or Firebase
